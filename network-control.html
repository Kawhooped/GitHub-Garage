Control boundaries

This first connected control surface can discover public repositories and route you to the correct editor. It does not yet write files directly from this page.

Direct in-page editing across public and private repositories requires a secured server-side gateway, GitHub authorization, per-repository permissions, and an auditable commit flow. No credentials are stored in this static page.

Private projects remain private. No private repository names, paths, or contents are loaded into this public control room.
