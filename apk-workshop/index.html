02 / Build the APK

The browser creates the Android project. A build runner compiles it into an APK.

2
Run the Android buildUpload the ZIP to a GitHub repository. Its included Actions workflow builds a debug APK.
3
Download your APKGet the APK from the completed GitHub Actions artifact and install it on your Android device.
Build status: project generator
This first version generates the Android project bundle. It does not compile APKs on this website yet. A secure remote build service is the next integration; no GitHub token or signing key is requested or stored here.
Create a new GitHub repository, upload the unzipped project contents, then open Actions and run “Build Android APK”. When the workflow finishes, download the artifact named android-debug-apk. For Play Store release builds, add protected signing secrets and a release workflow.
