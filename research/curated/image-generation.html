1. How diffusion generation works

Many widely used image generators are based on diffusion: a model learns to reverse a noise-corruption process and generate an image conditioned on text or other inputs. Real systems add components for text encoding, latent representations, schedulers, image decoding, and optional conditioning.

Practical consequence: the visible prompt is only one part of the workflow. Model choice, sampler/scheduler, resolution, guidance, seeds, conditioning inputs, and post-processing can materially change results.

3. Stable Diffusion and Stability AI

Stable Diffusion is a family of image-generation models and workflows, not one single application. The model weights, hosted API, and community interfaces are separate parts of the ecosystem.

Stability AI's official Core Models page lists Stable Diffusion 3.5 Medium, Large, and Large Turbo among its models, alongside earlier model families. Its page states that commercial use of the listed Core Models is governed by the applicable Stability AI agreement. Do not assume the same terms apply to every checkpoint or community derivative.

  • Stability AI Core Models — model list and applicable agreement scope.
  • Stability AI API reference — hosted generation/editing endpoints, authentication, request formats, and errors.

4. Local versus hosted generation

Local workflow

Run models on your own computer using a compatible UI or runtime. More control over files and workflow; hardware requirements can be substantial. Check GPU memory and supported model formats before downloading.

Hosted API

Send prompts and inputs to a provider. Easier to use from lightweight devices and web apps, but requires credentials and introduces usage costs, provider terms, and data-handling considerations.

Hybrid workflow

Use a local interface for workflow design and hosted inference for heavy jobs, or use hosted tools for exploration and local models for repeatable/private work.

5. How to choose a model

  1. Define the output: photorealism, illustration, typography, product imagery, editing, or video.
  2. Test prompt adherence and composition using the same small benchmark prompt set.
  3. Compare quality at the resolution and aspect ratio you actually need.
  4. Measure generation time and total cost, including retries and upscaling.
  5. Inspect license terms for commercial use, redistribution, derivatives, and attribution.
  6. Check whether model weights, custom nodes, extensions, or hosted services introduce separate terms.
