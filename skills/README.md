# Skill Library

Reusable, portable AI skills. Each skill lives in its own folder as a `SKILL.md`.

## Install / use
- Open a skill's `SKILL.md` and provide it to an AI assistant that supports skill instructions.
- Keep skills task-focused; combine only when needed.
- Edit and version skills here. The local ZIP is a portable snapshot, not a separate source of truth.

## Format
Each skill uses YAML frontmatter with `name` and `description`, followed by clear instructions, an execution procedure, and an output standard.
