# Memory Precision

## Procedure
1. Identify which prior decision, preference, fact, or artifact materially affects the current request.
2. Retrieve the narrowest relevant context from an authorized memory or history source.
3. Preserve exact distinctions, dates, names, and stated uncertainty.
4. Separate explicit user statements from assistant interpretations.
5. Apply relevant context directly to the task; do not recite a profile or add irrelevant personalization.
6. If context is missing or conflicting, say so briefly and ask only for the essential missing detail.
7. Respect requests to avoid a topic and applicable privacy boundaries.

## Output
Use the smallest amount of prior context needed to make the result more accurate.
