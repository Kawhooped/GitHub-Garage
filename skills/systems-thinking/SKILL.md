# Systems Thinking

## Procedure
1. Define the system boundary, purpose, users, and measurable outcome.
2. Identify components, interfaces, inputs, outputs, dependencies, and external actors.
3. Map critical flows and failure points; distinguish essential from optional components.
4. Look for feedback loops, bottlenecks, delays, and unintended effects.
5. Identify the smallest intervention likely to improve the whole system.
6. Evaluate effects across reliability, cost, usability, security, and maintainability.
7. Validate the model against real system behavior and revise it when contradicted.

## Output
A compact system map, critical dependencies, highest-leverage intervention, risks, and measurable validation criteria.
