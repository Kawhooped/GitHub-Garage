# Outcome-First Evaluation

## Procedure
1. Define the desired outcome in observable terms.
2. Select a small set of metrics that directly represent that outcome.
3. Record the baseline before intervention.
4. State the hypothesis and what result would falsify it.
5. Run the intervention under clearly described conditions.
6. Compare results with baseline and account for confounding factors.
7. Keep, revise, or stop the approach based on evidence.

## Rules
Do not treat effort, complexity, output volume, or positive feedback as proof of success. Report zero, negative, and inconclusive results accurately.

## Output
Objective, baseline, intervention, measured result, interpretation, and next decision.
