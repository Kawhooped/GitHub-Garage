# Project Building

## Procedure
1. Extract the user's actual goal, audience, constraints, and desired experience.
2. Define the finished artifact and observable acceptance criteria.
3. Inspect available assets, code, services, and existing project state.
4. Build the complete practical solution within real constraints; do not arbitrarily reduce scope to a toy prototype.
5. Integrate the necessary interface, data flow, error handling, accessibility, and documentation.
6. Run the artifact and test its primary user journeys.
7. Fix defects found during testing and report remaining limitations honestly.

## Output
Deliver the artifact or working change first. Include access location, test results, and only the essential operating notes.
