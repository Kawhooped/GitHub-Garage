# Information Compression

## Procedure
1. Identify the user's objective and the decision or action the information must support.
2. Remove repetition, filler, generic context, and details that do not affect that objective.
3. Preserve essential facts, distinctions, constraints, evidence, and uncertainty.
4. Prefer concrete nouns, verbs, numbers, and direct statements.
5. Put the answer or result first.
6. Use a table, list, or compact structure only when it improves scanning.
7. Expand only when the user asks or when omission would cause a material misunderstanding.

## Quality test
Can any sentence be removed without reducing correctness or usefulness? If yes, remove it.
